# 🛡️ درع التحكم في منافذ USB | USB Port Controller Shield

تطبيق أمني احترافي متكامل للتحكم في منافذ USB، حظر الفلاشات، تفعيل وضع القراءة فقط للحماية من تسريب ونسخ البيانات، والعمل الدائم في الخلفية مع إقلاع الويندوز ومحمي بكلمة سر رئيسية مشفرة.

---

## 🌟 الميزات الاحترافية (Enterprise Features)

1. **معالج تثبيت رسمي احترافي (Official Setup.exe Installer)**:
   - تثبيت التطبيق في مسار برامج النظام المعتمد: `C:\Program Files\USBPortControllerShield`.
   - إنشاء اختصارات رسمية على **سطح المكتب (Desktop)** و **قائمة ابدأ (Start Menu)**.
   - تسجيل البرنامج رسمياً في لوحة تحكم الويندوز **(Add / Remove Programs - Apps & Features)**.
   - يدعم **إلغاء التثبيت النظيف (Clean Uninstallation)** مع حذف كامل الاختصارات والملفات بضغطة زر.

2. **دعم التوافق مع مختلف الشاشات والأجهزة (Per-Monitor High-DPI Scaling)**:
   - دعم التوافق الكامل مع مختلف دقات الشاشات (Full HD, 2K, 4K, 8K) ومختلف نسب التكبير (100%, 125%, 150%, 200%) بدون أي ضبابية أو تشوه.

3. **دعم كامل لجميع إصدارات الويندوز (Cross-Windows Compatibility)**:
   - متوافق 100% مع Windows 11, Windows 10, Windows 8.1, Windows 7, وسيرفرات Windows Server بدون الحاجة لأي برامج إضافية.

4. **دعم ثنائي اللغة فوري (عربي / English)**:
   - تبديل فوري بضغطة زر مع ضبط اتجاه الواجهة (`RTL` / `LTR`).

5. **شعار وأيقونة مخصصة مدمجة (App Logo & Embedded .ico)**.

6. **حماية أمنية وتشفير كامل (SHA-256 + Salt)** مع حظر الفلاشات ومنع نسخ البيانات.

## 🚀 كيفية التثبيت والاستخدام (Installation & Usage)

### الخيار 1: التثبيت الرسمي عبر معالج التنصيب (موصى به)
- شغّل الملف [`Setup.exe`](file:///d:/%D8%B4%D8%A8%D9%83%D9%87/%D8%A7%D8%BA%D9%84%D8%A7%D9%82%20%20%D8%A7%D9%84%D9%85%D8%A7%D9%81%D8%B0/Setup.exe).
- اختر خيارات الاختصارات وانقر **بدء التنصيب والتثبيت الآن**.
- سيتم تثبيت البرنامج وفتحه تلقائياً وإضافته لقائمة ابدأ وسطح المكتب ولوحة التحكم.

### الخيار 2: التشغيل المباشر بدون تثبيت (Portable Mode)
- يمكنك تشغيل [`USBController.exe`](file:///d:/%D8%B4%D8%A8%D9%83%D9%87/%D8%A7%D8%BA%D9%84%D8%A7%D9%82%20%20%D8%A7%D9%84%D9%85%D8%A7%D9%81%D8%B0/USBController.exe) مباشرة من أي مكان أو نقله على فلاشة واستخدامه كأداة محمولة.
